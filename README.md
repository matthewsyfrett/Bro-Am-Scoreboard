# Bro-Am Live Golf

Live mobile scoreboard for 8 golfers and 3 golf days.

Format:
- Day 1 Game 1: 2-man Best Ball (net)
- Day 1 Game 2: Individual Stroke Play (net)
- Day 2: 2-man Scramble (net)
- Day 3: Individual Stroke Play (net)

Preloaded golfers and default pairings are included in data/trip.json.

Run locally with:
`npm install`
`npm start`

The app serves on PORT (default 3000) and exposes /api/trip, /api/scores, /api/reset-scores.
